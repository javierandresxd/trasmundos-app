# Trasmundos · páginas públicas

Página de descarga, política de privacidad y soporte de
[Trasmundos](https://apps.apple.com/app/id6836825506), de Kaha Innovations SpA. Se publican con GitHub Pages porque App Store Connect
y Google Play exigen una dirección pública para cada una.

- [Descarga](https://javierandresxd.github.io/trasmundos-app/): a donde llevan los QR de las piezas para redes. En iPhone y iPad salta a la App Store.
- [Política de privacidad](https://javierandresxd.github.io/trasmundos-app/privacidad.html)
- [Soporte](https://javierandresxd.github.io/trasmundos-app/soporte.html)

La política se genera desde el repositorio del juego (`legal/privacidad.md` y
`legal/privacy.md`, con `scripts/make-privacy-page.mjs`). Si hay que cambiarla,
se cambia allá y se copia aquí el resultado; no se edita este archivo a mano.

La página de descarga (`index.html`, `og.png`, `icono.png`) sale de `marketing/landing/` en el
repositorio del juego; también se cambia allá y se copia aquí.
